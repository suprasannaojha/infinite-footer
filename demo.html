🎨 Infinite Footer Web Component

A framework-agnostic web component that creates an infinite scrolling footer with a canvas-based trailing text effect. Works seamlessly with vanilla JavaScript, React, Vue, Angular, and any other framework.

Scroll down to see the effect in action! The footer will loop infinitely, changing text as you continue scrolling.

📦 Installation

Simply include the component script in your HTML:

<script type="module" src="infinite-footer.js"></script>

🚀 Basic Usage (Vanilla HTML)

Add the component to your HTML:

<infinite-footer text="DEVELOPERS" text-color="#1d1d1d" bg-color="#f5f5f5"> </infinite-footer>

⚛️ React Integration

Use refs to access properties and methods:

import React, { useRef, useEffect } from 'react'; // Import the web component (registers it globally) import './infinite-footer.js'; function App() { const footerRef = useRef(null); useEffect(() => { const footer = footerRef.current; // Set properties (better than attributes for React) footer.text = "HELLO REACT"; footer.texts = ["HELLO REACT", "Still scrolling?", "Goodbye!"]; footer.textColor = "#61dafb"; // Listen to events const handleLoopComplete = (e) => { console.log('Loop', e.detail.loopCount, '-', e.detail.currentText); }; footer.addEventListener('loop-complete', handleLoopComplete); return () => { footer.removeEventListener('loop-complete', handleLoopComplete); }; }, []); return ( <div> <h1>My React App</h1> <infinite-footer ref={footerRef}></infinite-footer> </div> ); }

🟢 Vue 3 Integration

Use template refs and v-bind:

<template> <div> <h1>My Vue App</h1> <infinite-footer ref="footerRef" :text="footerText" text-color="#42b883" @loop-complete="onLoopComplete"> </infinite-footer> </div> </template> <script setup> import { ref, onMounted } from 'vue'; // Import the web component import './infinite-footer.js'; const footerRef = ref(null); const footerText = ref('HELLO VUE'); onMounted(() => { // Access component via ref const footer = footerRef.value; footer.texts = ['HELLO VUE', 'Keep going?', 'Au revoir!']; }); const onLoopComplete = (event) => { console.log('Loop completed:', event.detail); }; </script>

🅰️ Angular Integration

Add CUSTOM_ELEMENTS_SCHEMA and use property binding:

// app.module.ts or component standalone config import { CUSTOM_ELEMENTS_SCHEMA } from '@angular/core'; // Import the web component in main.ts or component import './infinite-footer.js'; @NgModule({ schemas: [CUSTOM_ELEMENTS_SCHEMA] }) // component.ts import { Component, ViewChild, ElementRef } from '@angular/core'; @Component({ selector: 'app-root', template: ` <h1>My Angular App</h1> <infinite-footer #footer [text]="footerText" text-color="#dd0031" (loop-complete)="onLoopComplete($event)"> </infinite-footer> ` }) export class AppComponent { @ViewChild('footer') footerElement!: ElementRef; footerText = 'HELLO ANGULAR'; ngAfterViewInit() { const footer = this.footerElement.nativeElement; footer.texts = ['HELLO ANGULAR', 'Still here?', 'Done!']; } onLoopComplete(event: CustomEvent) { console.log('Loop:', event.detail.loopCount); } }

⚙️ API Reference

Attributes / Properties:

  • text - Primary footer text (default: "DEVELOPERS")
  • text-color - Text stroke color (default: "#1d1d1d")
  • bg-color - Background color (default: "#f5f5f5")
  • stroke-width - Text outline width (default: 2.5)
  • font-family - Font family (default: "sans-serif")
  • loop-enabled - Enable infinite loop (default: true)
  • texts - Array of texts for loop iterations (JSON string)
  • lerp-factor - Animation smoothness 0-1 (default: 0.1)

Events:

  • loop-complete - Fired when infinite loop resets (detail: {loopCount, currentText})
  • scroll-progress - Fired on scroll (detail: {progress, loopCount, normalizedScroll})

Methods:

  • reset() - Reset the footer to initial state

Read-only Properties:

  • currentLoopCount - Current iteration number
  • currentScrollProgress - Normalized scroll position
