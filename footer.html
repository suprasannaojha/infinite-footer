Welcome to the Demo

This is a recreation of the Stripe.dev footer effect. Scroll down to see the magic happen when you reach the footer.

The effect creates text that moves upward as you scroll, leaving trails behind - just like the original Stripe implementation.

How It Works

The key trick is that the canvas only clears the area ABOVE the current text position. Previous renders remain visible below, creating the trail effect naturally.

When you reach the bottom of the footer, the page scrolls back to the top of the footer, creating an infinite scroll illusion.

The Technology

Canvas 2D rendering with destination-out compositing to create outline-only text. The text is stroked first, then the fill is "cut out" using composite operations.
